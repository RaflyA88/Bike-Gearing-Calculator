## Technical Calculations Explained

### Gear Ratio
```
Gear Ratio = Chainring Teeth ÷ Cog Teeth
Example: 50 ÷ 11 = 4.55
```
Higher ratio = harder to pedal, faster speed

### Gear Inches
```
Gear Inches = (Chainring ÷ Cog) × Wheel Diameter (inches)
Example: (50 ÷ 11) × 27 = 122.7"
```
Traditional measurement of gear "size"
- Below 30" = Very easy (steep climbing)
- 30-50" = Easy (hills)
- 50-75" = Medium (rolling terrain)
- 75-100" = Hard (flats, speed)
- Above 100" = Very hard (sprinting)

### Speed Calculation
```
Speed (km/h) = Gear Inches × π × Cadence × 0.001885
Example: 122.7 × 3.14159 × 90 × 0.001885 = 65.4 km/h
```

### Gain Ratio
```
Gain Ratio = (Chainring ÷ Cog) × (Wheel Radius ÷ Crank Length)
```
More accurate than gear inches for actual mechanical advantage
