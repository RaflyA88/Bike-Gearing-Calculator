# 🚴 Kalkulator Gearing Sepeda - Ringkasan Program

## 📋 Latar Belakang

### Permasalahan
Pesepeda, baik pemula maupun berpengalaman, sering kesulitan memahami sistem gearing sepeda. Pertanyaan seperti "Apakah sepeda ini bisa menanjak tanjakan curam?", "Rasio gear mana yang terbaik untuk gaya bersepeda saya?", atau "Seberapa cepat saya bisa melaju di gear tertinggi?" memerlukan perhitungan matematis yang rumit, memakan waktu, dan rawan kesalahan jika dilakukan secara manual.

Toko sepeda dan mekanik juga menghadapi tantangan saat membantu pelanggan memilih pengaturan gearing yang tepat. Tanpa alat visual, sulit menjelaskan rasio gear, kecepatan, dan keuntungan mekanis kepada pelanggan yang tidak familiar dengan terminologi bersepeda.

### Kebutuhan
Terdapat kebutuhan yang jelas untuk sebuah alat yang mudah diakses dan ramah pengguna yang:
- Melakukan perhitungan rasio gear secara instan
- Memvisualisasikan progresi gear dengan jelas
- Mendukung semua jenis sepeda (road, gravel, mountain, fixie, city)
- Bekerja offline tanpa memerlukan koneksi internet
- Menyediakan konfigurasi preset untuk jenis sepeda umum
- Membantu pengguna membuat keputusan pembelian yang tepat

### Solusi
Kalkulator Gearing Sepeda dikembangkan sebagai solusi komprehensif untuk mengatasi tantangan-tantangan ini. Aplikasi ini tersedia dalam versi desktop Windows dan web, membuatnya dapat diakses oleh semua pesepeda tanpa memandang keahlian teknis atau preferensi platform mereka.

## 🎯 Tujuan

### Tujuan Utama

1. **Menyederhanakan Perhitungan Gear**
   - Menghilangkan perhitungan manual untuk rasio gear
   - Memberikan hasil yang instan dan akurat

   - Membuat grafik interaktif yang menunjukkan progresi gear

3. **Mendukung Semua Jenis Sepeda**
   - Sepeda road (gearing compact dan standard)
   - Sepeda gravel (konfigurasi 1x dan 2x)
   - Sepeda mountain (kaset rentang lebar)
   - Sepeda fixie/track (rasio single-speed)
   - Sepeda kota (pengaturan komuter)

4. **Aksesibilitas**
   - Gratis digunakan tanpa biaya berlangganan
   - Bekerja offline (aplikasi desktop)
   - Tidak memerlukan instalasi (portabel)
   - Kompatibilitas lintas platform (versi web)

5. **Pengalaman Pengguna**
   - Antarmuka intuitif tidak memerlukan pengetahuan teknis
   - Konfigurasi preset untuk pengaturan cepat
   - Perhitungan real-time saat pengguna mengetik
   - Desain ramah mobile

### Tujuan Sekunder

1. **Membantu Toko Sepeda**
   - Menyediakan alat untuk konsultasi pelanggan
   - Alat bantu visual untuk menjelaskan perbedaan gear
   - Tampilan profesional untuk kredibilitas

2. **Nilai Edukasi**
   - Mengajarkan pengguna tentang rasio gear

   - Menunjukkan hubungan antara gearing dan kecepatan

3. **Dukungan Komunitas**
   - Pendekatan open-source untuk transparansi

   - Distribusi gratis untuk semua pesepeda

### Opsi Deployment

#### Aplikasi Desktop
1. **Build PyInstaller:**
   ```bash
   pyinstaller --onefile --windowed --add-data="public;public" bike_calculator_app.py
   ```

2. **Output:**
   - `dist/BikeGearingCalculator.exe` (50 MB)

#### Aplikasi Web

1. **Server Python:**
   ```bash
   python serve.py
   ```
   - Port: 3000
   - Auto-serve dari folder `public/`

2. **Server Node.js:**
   ```bash
   node server.js
   ```
   - Port: 3000
   - Static file serving

3. **Akses File Langsung:**
   - Buka `public/index.html` di browser
   - Terbatas oleh CORS untuk resource CDN
