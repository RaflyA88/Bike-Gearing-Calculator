## 🚀 Quick Start

### For Social Media
1. Open `social_media_poster.html` in your browser
2. Click the save button for your desired format
3. Upload to your social media platform

### For Printing
1. Open `promotional_poster.html` or `simple_flyer.html`
2. Press Ctrl+P (Windows) or Cmd+P (Mac)
3. Choose:
   - Print directly
   - Save as PDF for print shop

## 💡 Tips

1. **Test Print First** - Print one copy before bulk printing
2. **Check Colors** - Screen colors may differ from print
3. **Use Good Paper** - Glossy for posters, matte for flyers
4. **Optimize for Web** - Save social media images as PNG
5. **Track Results** - Monitor which formats get best engagement
