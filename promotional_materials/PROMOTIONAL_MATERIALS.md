#### Method 2: Save as PDF
1. Open any HTML file in your browser
2. Press **Ctrl+P** (or Cmd+P on Mac)
3. Select "Save as PDF" or "Microsoft Print to PDF"
4. Save to your computer
5. Take PDF to print shop

1. Open HTML file in browser

## 📋 Customization Guide

### Change Colors
Open any HTML file and find the `<style>` section. Update:

```css
/* Primary gradient */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Change to your colors */
background: linear-gradient(135deg, #YOUR_COLOR1 0%, #YOUR_COLOR2 100%);
```

### Add Your Logo
Find the bike icon section:
```html
<i class="fas fa-bicycle"></i>
```

Replace with:
```html
<img src="your-logo.png" alt="Logo">
```

### Change Text
Simply edit the HTML text between tags:
```html
<h1>BIKE GEARING CALCULATOR</h1>
<!-- Change to -->
<h1>YOUR TEXT HERE</h1>
```

### Add QR Code
1. Generate QR code at qr-code-generator.com
2. Download QR code image
3. Add to poster:
```html
<img src="qr-code.png" alt="Download" style="width: 200px;">
```
