## 🚀 How to Use Them

### Quick Start

1. **Open any file** in your web browser
2. **Click the print/save button** (top right)
3. **Choose action:**
   - Print directly
   - Save as PDF
   - Save for social media

### For Social Media

**Open:** `social_media_poster.html`

**Click buttons to save:**
- 📷 "Save Instagram" → For Instagram feed
- 📘 "Save Facebook" → For Facebook/Twitter
- 📱 "Save Story" → For Instagram/Facebook Stories

### For Printing

**Open:** `promotional_poster.html` or `simple_flyer.html`

**Press:** Ctrl+P (Windows) or Cmd+P (Mac)

**Choose:**
- Print to physical printer
- Save as PDF
- Take PDF to print shop

## 💡 Quick Tips

1. **Test print first** - Try one copy before bulk printing
2. **Check colors** - Screen colors may differ from print
3. **Use good paper** - Glossy for posters, matte for flyers
4. **Optimize for web** - Save social media images as PNG
5. **Track results** - Monitor which formats get best engagement
