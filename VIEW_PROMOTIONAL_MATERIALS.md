# 🎨 View Promotional Materials

All promotional materials for the Bike Gearing Calculator are located in the **`promotional_materials`** folder.

## 📂 Quick Access

### Open the Folder
```
📁 promotional_materials/
```

## 📋 What's Inside

### 🖼️ Posters & Graphics (HTML Files)

1. **promotional_poster.html**
   - Full-size print poster
   - Open in browser → Print or Save as PDF

2. **social_media_poster.html**
   - 3 social media formats (Instagram, Facebook, Story)
   - Open in browser → Click save buttons

3. **simple_flyer.html**
   - A4 simple flyer for handouts
   - Open in browser → Print or Save as PDF

### 📚 Documentation Files

4. **PROMOTIONAL_MATERIALS.md**
   - Complete guide with instructions
   - Customization tips
   - Social media captions
   - Marketing checklist

5. **PROMOTIONAL_SUMMARY.md**
   - Quick reference guide

6. **README.md**
   - Folder overview

## 🚀 Quick Start

### Method 1: Open Folder
1. Navigate to `promotional_materials` folder
2. Double-click any HTML file to open in browser
3. Use print button or save for web

### Method 2: Direct Path
Windows Explorer:
```
promotional_materials\promotional_poster.html
promotional_materials\social_media_poster.html
promotional_materials\simple_flyer.html
```
