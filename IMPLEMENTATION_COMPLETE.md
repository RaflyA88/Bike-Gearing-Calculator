## 🚀 How to Use

### For Users

1. **Open the application**
   - Web: Open `public/index.html` in browser
   - Desktop: Run `BikeGearingCalculator.exe`
   - Server: Run `python serve.py` or `node server.js`

2. **Enter gearing or use preset**
   - Type in chainrings and cassette
   - Or click any preset button

3. **Scroll to recommendations**
   - Purple section below results
   - 4 cards with analysis

4. **Read recommendations**
   - Check terrain ratings
   - Find riding type matches
   - Browse compatible groupsets
   - Review upgrade suggestions

### For Developers

1. **Review code changes**
   - Check `public/script.js` for recommendation functions
   - Review `public/styles.css` for styling

Add new groupset:
```javascript

    brand: 'Brand Name',
    name: 'Groupset Name',
    level: 'Performance', // Professional/Performance/Sport/Budget
```
