## Core Message (All Descriptions)

### What It Does
Calculates bicycle gear ratios, speeds, and cadence to help cyclists choose optimal gearing.

### Who It's For
Road cyclists, gravel riders, mountain bikers, fixie enthusiasts, city commuters, bike mechanics, and bike shoppers.

### Key Benefits
1. **Instant calculations** - No manual math needed
2. **Visual charts** - See entire gear range at a glance
3. **11 presets** - Quick setup for any bike type
4. **Smart decisions** - Compare before buying

### Unique Features
- Windows desktop app (no browser needed)
- Works completely offline
- 11 built-in configurations
- Interactive gear charts
- Speed-to-cadence calculator
- 100% free forever

## Technical Highlights

### Calculations Performed
- Gear Ratio (Chainring ÷ Cog)
- Gear Inches (visual measurement)
- Gain Ratio (mechanical advantage)
- Speed at various cadences
- Required cadence for target speed

### Supported Configurations
- Road: Compact, Standard
- Gravel: 1x, 2x
- Mountain: Wide range
- Fixie: Standard, Fast, Easy
- City: 26", 700c, Comfort
- Custom: Any setup
